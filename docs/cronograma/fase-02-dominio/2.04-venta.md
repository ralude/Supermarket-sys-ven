# Sub-fase 2.04: Venta

- **Fase:** [Fase 2 - Codigo de negocio](./README.md)
- **Estado:** Pendiente

## Objetivo

Implementar el agregado Sale y el flujo de venta sin persistencia ni impresora.

## Tareas

- [ ] Crear una venta en estado DRAFT.
- [ ] Agregar y eliminar items con snapshots de producto.
- [ ] Aplicar descuentos con reglas y autorizacion configurables.
- [ ] Calcular IVA, IGTF cuando aplique y total determinista.
- [ ] Registrar pagos mixtos con tasas explicitas.
- [ ] Completar y anular con estados, motivos y eventos validos.
- [ ] Probar casos de uso outside-in con fakes de puertos.

## Criterio de salida

El flujo `Venta -> Item -> eliminar -> descuento -> IVA -> total -> pago -> cierre` pasa unit tests y no imprime.
