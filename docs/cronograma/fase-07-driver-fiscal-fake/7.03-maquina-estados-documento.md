# Sub-fase 7.03: Maquina de estados del documento

- **Fase:** [Fase 7 - Driver fiscal fake](./README.md)
- **Estado:** Pendiente

## Objetivo

Persistir y recuperar el estado de emision ante fallos y reinicios.

## Tareas

- [ ] Implementar PENDING, PRINTING, ISSUED, ERROR, RETRYING y FAILED.
- [ ] Impedir reintentos ciegos cuando el estado del dispositivo es desconocido.
- [ ] Probar reconciliacion despues de reinicio.
- [ ] Mantener ISSUED inmutable.

## Criterio de salida

Una factura no se duplica por un corte despues de enviar el comando.
