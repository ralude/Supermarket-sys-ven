# Sub-fase 11.01: Autenticacion

- **Fase:** [Fase 11 - Seguridad](./README.md)

## Objetivo

Identificar al operador de forma segura.

## Tareas

- [ ] Implementar flujo de login o PIN segun politica aprobada.
- [ ] Almacenar credenciales solo mediante adaptador seguro.
- [ ] Aplicar limite de intentos y bloqueo.
- [ ] Probar no exposicion de credenciales.

## Criterio de salida

Toda operacion sensible tiene un actor autenticado y trazable.
