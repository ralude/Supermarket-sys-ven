# Sub-fase 11.03: JWT y sesiones

- **Fase:** [Fase 11 - Seguridad](./README.md)

## Objetivo

Proteger sesiones y transporte HTTP sin exponer secretos al renderer.

## Tareas

- [ ] Elegir politica de sesiones y expiracion.
- [ ] Implementar JWT o sesiones seguras segun despliegue.
- [ ] Validar revocacion y renovacion.
- [ ] Probar expiracion, replay y permisos insuficientes.

## Criterio de salida

Las peticiones HTTP tienen una identidad valida y una sesion controlable.
