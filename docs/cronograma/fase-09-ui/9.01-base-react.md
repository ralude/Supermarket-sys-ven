## Avance ejecutado

El renderer recupera la sesión autenticada mediante cookie, muestra acceso por
PIN cuando corresponde y distingue carga, sesión ausente y error de conexión.
El shell usa navegación hash, HTML semántico y CSS nativo, muestra siempre el
modo fiscal `SIMULACIÓN` y deja los flujos 9.02–9.07 como destinos explícitos
sin datos ficticios ni operaciones adelantadas.

El cliente HTTP consume los contratos compartidos, conserva
`ProblemDetails`, incluye cookies y no recibe tokens. Vite reenvía `/api` a
Fastify en desarrollo y preview para mantener el mismo origen. Preload continúa
exponiendo únicamente la plataforma.

## Criterio de salida

La UI inicia y delega operaciones a la API sin acceder a SQLite o Node.js.
