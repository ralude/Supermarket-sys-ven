# Sub-fase 6.03: Venta y salida

- **Fase:** [Fase 6 - Inventario](./README.md)
- **Estado:** Pendiente

## Objetivo

Convertir una venta completada en salidas de stock idempotentes.

## Tareas

- [ ] Consumir SaleCompleted como contrato de integracion.
- [ ] Seleccionar lote segun politica aplicable.
- [ ] Crear salidas sin stock negativo.
- [ ] Probar reentrega del evento.

## Criterio de salida

Una venta genera una sola salida por item y nunca modifica cantidades directamente.
