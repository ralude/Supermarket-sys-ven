## Criterio de salida

La conexion se abre de forma verificable y nunca desde renderer o mas de un servidor.

## Decisiones aplicadas

- Cada archivo SQLite adquiere un lock de ownership junto a la base.
- Un segundo proceso que use el driver recibe `DATABASE_NODE_LOCKED`.
- Los locks de procesos terminados se recuperan y `close()` libera el ownership.
- `:memory:` queda reservado para pruebas y no usa lock de archivo.
