## Criterio de salida

## Notas y decisiones

Configuracion elegida: ESLint 9 flat config centralizada en la raiz del monorepo, con `typescript-eslint` (`recommended`), `globals` (node para servidor/drivers/paquetes, browser para renderer) y `eslint-plugin-react-hooks` (solo archivos `.tsx` del renderer).
No se agregan scripts `lint` por paquete: la config centralizada con `eslint .` desde raiz cubre todo el monorepo y evita duplicacion.

El script del pipeline se nombro `pnpm pipeline` en lugar de `pnpm ci` porque `ci` es un comando nativo de pnpm (equivalente a `npm clean-install`). El pipeline actual ejecuta `lint → typecheck → test`. Coverage y empaquetado Electron estan documentados como etapas pendientes en `ci-cd.md`.
