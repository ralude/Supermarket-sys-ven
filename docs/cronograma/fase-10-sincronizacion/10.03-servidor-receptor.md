# Sub-fase 10.03: Servidor receptor

- **Fase:** [Fase 10 - Sincronizacion](./README.md)
- **Estado:** Pendiente

## Objetivo

Recibir eventos de terminales autonomas en el nodo coordinador y procesarlos idempotentemente.

## Tareas

- [ ] Implementar endpoint tecnico de entrega de eventos.
- [ ] Validar envelope y autenticacion del transporte.
- [ ] Registrar deduplicacion y errores transitorios.
- [ ] Confirmar solo despues de persistir el evento.
- [ ] Crear discrepancias auditables para conflictos de inventario que no puedan aplicarse.

## Criterio de salida

El servidor acepta eventos validos y rechaza o reintenta los demas sin perderlos.
