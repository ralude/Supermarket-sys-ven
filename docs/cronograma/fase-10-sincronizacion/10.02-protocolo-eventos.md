# Sub-fase 10.02: Protocolo de eventos

- **Fase:** [Fase 10 - Sincronizacion](./README.md)
- **Estado:** Pendiente

## Objetivo

Definir contratos versionados para transportar eventos entre nodos.

## Tareas

- [ ] Definir envelope con eventId, aggregateId, aggregateType, aggregateVersion, originNodeId y occurredAt.
- [ ] Versionar payloads de integracion.
- [ ] Definir deduplicacion del receptor.
- [ ] Probar eventos desconocidos y versiones incompatibles.
- [ ] Probar rechazo de escrituras que violen el ownership del agregado.

## Criterio de salida

El protocolo transporta hechos versionados y no replicas de tablas.
