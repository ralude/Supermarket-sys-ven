# Sub-fase 8.02: Parser de protocolo

- **Fase:** [Fase 8 - Integracion serial](./README.md)
- **Estado:** Pendiente

## Objetivo

Parsear tramas seriales y validar CRC sin mezclar transporte con negocio.

## Tareas

- [ ] Definir framing y delimitadores.
- [ ] Parsear respuestas ACK y NAK.
- [ ] Validar CRC y mensajes incompletos.
- [ ] Probar ruido, truncamiento y bytes inesperados.

## Criterio de salida

El parser produce respuestas tipadas y no acepta tramas invalidas.
