# Sub-fase 8.03: Command queue

- **Fase:** [Fase 8 - Integracion serial](./README.md)
- **Estado:** Pendiente

## Objetivo

Serializar comandos y conservar los pendientes ante desconexion.

## Tareas

- [ ] Implementar cola con orden y prioridad definida.
- [ ] Persistir comando, intento y estado.
- [ ] Impedir comandos concurrentes incompatibles.
- [ ] Probar reinicio con comandos pendientes.

## Criterio de salida

La cola es durable y no pierde ni duplica comandos.
