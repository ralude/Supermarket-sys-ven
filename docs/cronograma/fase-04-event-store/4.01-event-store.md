# Sub-fase 4.01: Ledger de eventos

- **Fase:** [Fase 4 - Ledger, outbox y auditoria](./README.md)
- **Estado:** Pendiente

## Objetivo

Conservar hechos de negocio seleccionados, inmutables y append-only, para historia y proyecciones.

## Tareas

- [ ] Definir esquema versionado de eventos.
- [ ] Persistir `eventId`, agregado, version, payload y timestamp UTC.
- [ ] Impedir update o delete de eventos.
- [ ] Probar orden y duplicados.
- [ ] Verificar que repositorios cargan el estado relacional y no rehidratan agregados desde el ledger.

## Criterio de salida

Los hechos `Venta creada`, `Item agregado`, `Pago agregado` y `Venta cerrada` no desaparecen, pero el arranque operativo no depende de reproducirlos.
