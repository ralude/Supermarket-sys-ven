# Sub-fase 4.01: Event store

- **Fase:** [Fase 4 - Event Store](./README.md)
- **Estado:** Pendiente

## Objetivo

Conservar eventos de negocio inmutables y append-only.

## Tareas

- [ ] Definir esquema versionado de eventos.
- [ ] Persistir `eventId`, agregado, version, payload y timestamp UTC.
- [ ] Impedir update o delete de eventos.
- [ ] Probar orden y duplicados.

## Criterio de salida

Los hechos `Venta creada`, `Item agregado`, `Pago agregado` y `Venta cerrada` no desaparecen.
